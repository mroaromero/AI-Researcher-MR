## 🚀 Uso

### Ver todas las categorías:
```bash
python install-all-tech-skills.py --list
```

### Instalar TODAS las skills (~400+):
```bash
python install-all-tech-skills.py --all
```

### Instalar categorías específicas:
```bash
# Web3/Blockchain
python install-all-tech-skills.py --category web3-blockchain

# Game Development
python install-all-tech-skills.py --category game-dev

# AR/VR/XR
python install-all-tech-skills.py --category ar-vr-xr

# Data/ML/AI
python install-all-tech-skills.py --category data-ml-ai

# Systems Programming
python install-all-tech-skills.py --category systems-programming

# Mobile Native (iOS/Android)
python install-all-tech-skills.py --category mobile-native

# DevOps/Platform/SRE
python install-all-tech-skills.py --category devops-platform

# Testing Avanzado
python install-all-tech-skills.py --category testing-advanced

# Lenguajes/Frameworks
python install-all-tech-skills.py --category languages-frameworks

# Especialidades Técnicas
python install-all-tech-skills.py --category specialized-tech
```

### Opciones adicionales:
```bash
# Simular instalación (ver qué instalaría)
python install-all-tech-skills.py --all --dry-run

# Directorio específico
python install-all-tech-skills.py --all --dir ./mis-skills

# Instalación secuencial (más lento pero estable)
python install-all-tech-skills.py --all --sequential

# Más workers paralelos (más rápido)
python install-all-tech-skills.py --all --workers 10
```

## ⚠️ Importante

### ¿Estas skills existen realmente?

**NO necesariamente.** He incluido las skills que **deberían existir** para cada especialización técnica, basándome en:
- Las tecnologías más populares de cada área
- Las que probablemente la comunidad haya creado o creará
- Las que deberías buscar si existen

### Qué sucederá al ejecutar:

1. **Las que existan**: Se instalarán correctamente ✅
2. **Las que no existan**: Darán error (pero el script continúa) ❌
3. **Al final**: Tendrás un reporte de cuáles funcionaron

### Para verificar existencia antes:

```bash
# Instalar el skill "find-skills" primero
npx skills add vercel-labs/skills --skill find-skills

# Luego buscar skills específicas
# O visitar: https://skills.sh/
```

## 🐛 Solución de Problemas

### "npx: command not found"
```bash
# Instalar Node.js
# Ubuntu/Debian:
sudo apt-get install nodejs npm

# macOS:
brew install node

# Windows:
# Descargar de https://nodejs.org/
```

### Muchos timeouts
```bash
# Usar modo secuencial
python install-all-tech-skills.py --all --sequential
```

### Errores de permisos
```bash
chmod +x install-all-tech-skills.py
```
